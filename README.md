# Jordan Academy — أكاديمية الأردن

موقع تعليمي شخصي ذو هوية عامة، مخصص لعرض دورات الخط العربي واللغة العربية والدروس المدرسية. **ليس منصة اشتراكات للمعلمين الآخرين** ولا يعرض اسم مالك الأكاديمية في الواجهة.

## المعاينة
افتح `index.html` أو ارفع `index.html` و`style.css` و`app.js` إلى جذر مستودع GitHub Pages.

## ما يعمل
- صفحة رئيسية عربية متجاوبة بخط Noto Naskh Arabic.
- أقسام مجالات التعلم والميزات.
- معاينة إدارة عناوين دورات تحفظ محليًا في المتصفح فقط.

## تنبيه
لوحة المعاينة متاحة لأي زائر وليست لوحة إدارة محمية؛ لا تدخل بيانات حقيقية. لا توجد قاعدة بيانات أو تسجيل طلاب أو مدفوعات أو حماية للدروس بعد. المرحلة التالية هي بناء لوحة إدارة خاصة بصاحب الموقع مع تسجيل دخول آمن، وإدارة الدورات والدروس والاختبارات.
