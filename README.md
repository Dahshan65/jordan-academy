# Dahshan Academy — Prototype V1

العنوان المستهدف لاحقًا: academy.dahshansoft.com

## التشغيل
افتح `index.html` في متصفح حديث، أو ارفع الملفات الثلاثة `index.html`, `style.css`, `app.js` إلى استضافة ملفات ثابتة مثل GitHub Pages لتجربة العرض.

## ما يعمل الآن
- صفحة رئيسية متجاوبة باللغة العربية.
- عرض أكاديمية المؤسس.
- لوحة معلم تجريبية.
- إضافة وحذف عناوين دورات مع تخزينها محليًا في المتصفح.

## غير متاح بعد
لا يوجد تسجيل دخول أو قاعدة بيانات سحابية أو عزل حقيقي بين المعلمين أو دفع أو رفع فيديو أو حماية للمحتوى. لا تستخدم هذه النسخة لتسجيل طلاب حقيقيين أو جمع مدفوعات.

## المرحلة التالية
نقل الواجهة إلى Next.js App Router وربط Supabase Auth وPostgreSQL مع سياسات RLS للأكاديميات، ثم إنشاء CRUD حقيقي للدورات والطلاب والدروس. راجع سياسات الصلاحيات قبل النشر العام.
